## Stuff I'm Into Right Now

### Helix

I'm using Helix as my main text editor and IDE. This is a recent development -- I'd been using Neovim before. Helix is a much better experience because I don't have to configure it and because the object -> verb paradigm is more intuitive than Vim's verb -> object paradigm. It's a bit to get used to at first, but after a day you'll start flying.
